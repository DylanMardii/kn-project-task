## Discount Calculator (`1-discount-calculator.py`)

A desktop GUI application built with Python's **Tkinter** library that calculates the final price after applying a percentage discount.

### How to Run Locally

#### Prerequisites

- **Python 3.6+** installed on your computer

#### Steps

1. Open a terminal (Command Prompt, PowerShell, or bash).
2. Navigate to the project folder.
3. Run the script:

   ```bash
   python 1-discount-calculator.py
   ```

   > On some systems you may need to use `python3` instead of `python`.

4. A window will appear. Enter values and click **Calculate** or press **Enter**.

> **Note:** Tkinter comes pre-installed with Python on Windows and most Linux distributions. On macOS you may need to install it separately.

## Portfolio Website (`2-portfolio.html` + `script.js`)

A modern, responsive personal portfolio website built with **HTML5** and **Bootstrap 5**.

### How to Run Locally

This is a static website — no build tools or server required.

#### Option A — Open Directly (Simplest)

1. Navigate to the project folder location.
2. Double-click `2-portfolio.html` — it will open in your default web browser.

#### Option B — Using VS Code Live Server (Recommended)

1. Install the **Live Server** extension in VS Code.
2. Right-click `2-portfolio.html` in the VS Code file explorer.
3. Select **"Open with Live Server"**.
4. The site will open at `http://127.0.0.1:5500/2-portfolio.html`.
